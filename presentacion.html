Docker Compose — Servicio 1/2

Un solo comando levanta todo: docker compose up -d --build

🗄️  Servicio: base_datos

  • → Imagen oficial de MySQL 8
  • → Al arrancar por primera vez lee ticketpro.sql e inserta los datos semilla (admin + técnico con BCrypt)
  • → Los datos sobreviven reinicios gracias al volumen Docker volumen_datos_mysql
  • → ./ticketpro.sql:/docker-entrypoint-initdb.d/01-ticketpro.sql — monta el SQL en la carpeta especial de MySQL: cualquier .sql ahí se ejecuta automáticamente al crear el contenedor

Arquitectura — flujo de una petición

Todo pasa por la API REST. El frontend nunca habla directamente con MySQL.

🌐 Navegador
→
fetch() POST /api/auth/login { email, password }
⚙️ @RestController
→
Deserializa el JSON con @RequestBody y delega al servicio
🔒 BCrypt
→
Compara la contraseña con el hash de MySQL
🗄️ JpaRepository
→
Hibernate genera el SQL. Devuelve el objeto Usuario.
📦 ResponseEntity
→
El servidor responde { usuarioId, nombre, rol }. JS lo guarda en sessionStorage.
